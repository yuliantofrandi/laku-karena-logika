| Jenis | Paket | Spesifikasi | Harga/bulan |
|---|---|---|---|

| Shared Hosting | Medium | 2 CPU · 4 GB RAM · 5 GB | Rp600.000 |

| VPS Cloud Server | Small | 4 vCPU · 4 GB RAM · 32 GB | Rp900.000 |

| VPS Cloud Server | Large | 6 vCPU · 8 GB RAM · 32 GB | Rp1.150.000 |

Aturan:
- Pilih paket yang sesuai beban dari brief (web saja → Shared Hosting bisa cukup; web + API aplikasi mobile + database → VPS).
- Mulai **1 bulan sebelum go-live** (saat UAT dan rilis ke store), karena production sudah dibutuhkan saat itu. Staging tetap gratis dari Venturo.
- Deskripsi baris menyebut fungsi server (web, API mobile, database), spesifikasi paket, dan opsi upgrade paket.
- Klaim dukungan tim DevOps (monitoring, konfigurasi, optimasi, patching) **hanya untuk paket VPS**.
