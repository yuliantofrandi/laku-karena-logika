# Laku karena logika — marketplace

Marketplace plugin pribadi untuk **AI Marketing OS**: rangkaian skill Claude yang mengubah pengetahuan produk jadi output marketing untuk SaaS.

## Install

```
/plugin marketplace add yuliantofrandi/laku-karena-logika
/plugin install laku-karena-logika@laku-karena-logika
```

## Isi

| Plugin | Fungsi |
|---|---|
| `laku-karena-logika` | Kumpulan skill AI Marketing OS. Skill pertama: `business-knowledge`. |

Detail tiap plugin ada di `plugins/<nama>/README.md`.
